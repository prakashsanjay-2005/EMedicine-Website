# 💊 E-Medicine - Online Pharmacy Management System

E-Medicine is a full-stack online pharmacy management system that allows users to browse medicines, manage their shopping cart, place orders, view order history, and download order invoices.

The application also provides an Admin module for managing medicines, users, stock, and orders.

---

## 🚀 Project Features

### 👤 User Features

- User Registration
- User Login
- JWT-based Authentication
- Protected User Routes
- Browse Medicines
- Search Medicines
- View Medicine Price and Stock
- Add Medicines to Cart
- Increase Cart Quantity
- Decrease Cart Quantity
- Remove Items from Cart
- Place Orders
- View Order History
- View Order Items
- View Order Status
- Download Order Invoice as PDF
- View User Profile
- Contact Page

### 👨‍💼 Admin Features

- Admin Login
- Role-Based Authorization
- Admin Dashboard
- Add Medicines
- Update Medicines

- View All Orders
- Update Order Status
